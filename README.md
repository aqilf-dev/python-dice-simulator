# 🎲 Python Dice Simulator

Program simulator dadu berasaskan CLI yang dibuat menggunakan Python!

## 🌟 Ciri-ciri
- Set julat nombor dadu sendiri (minimum & maksimum).
- Delay masa rawak dengan modul `time` & `random` untuk efek *suspense*.
- *Error handling* lengkap untuk elak program *crash*.

## 🚀 Cara Guna
1. Pastikan Python 3 sudah dipasang.
2. Jalankan arahan:
   python dice_simulator.py
